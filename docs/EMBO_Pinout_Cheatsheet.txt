================================================================
EMBO — PINOUT CHEAT SHEET  (v3.4, ESP32-S3-WROOM-1-N4)
================================================================
Quick reference only. Full spec, rationale, and pre-submission checklist:
docs/EMBO_PCB_Design_Brief_v3_4.txt

CHANGED SINCE v2.4 (do not wire from memory — several GPIOs below now
carry a DIFFERENT signal than the old v2.4 sheet documented):
  - MCU corrected N8 -> N4 (no pinout impact, flash size only)
  - GPIO21, GPIO37, GPIO42 previously carried touch signals; they are now
    HX711 load-cell pins (added v3.2). Touch was relocated in v3.3 to
    GPIO12 (T_CS) / GPIO46 (T_DO); T_IRQ is NOT connected (polled instead).
  - TMC UART is now two separate pins, GPIO4 (TX) + GPIO44 (RX), not one
    bidirectional pin on GPIO4.
  - PDN_UART target pin on the MKS V2.0 module corrected v3.4: pin 5
    (direct), NOT pin 4 — opposite of every version through v3.3.
  - Motor connectors J4/J5 changed JST-XH 6-pin -> JST-PH 4-pin.
  - PSU input J14 changed 3.5mm -> 5.0mm screw terminal; on-board 8A
    backstop fuse F2 added (v3.4) after the off-board 5A T5A fuse F1.
  - TMC2209 MS1/MS2 address straps are now field jumpers, not hardwired.
  - Turbidity (I2C, GPIO3/43) and force sensing (HX711, GPIO21/37/42)
    added v3.2, both still present and hardened in v3.4.
  - 12x 220R series resistors added v3.4 on every ESP32-to-TMC2209
    control line (STEP/DIR/EN/PDN/MS1/MS2 x2) — GPIO-side short-fault
    protection, added after a hot-swap/spark incident on the fabricated
    v2.51 board. Electrically transparent (see design brief §7.6) but
    physically present in the signal path — don't probe past them and
    assume a dead short is at the GPIO itself.

just NC at the main-board connector — see design brief §8.3.

SPI speeds: ILI9341 via ribbon → 20 MHz max | XPT2046 → per chip, lower
            AD9833 direct → ~10 MHz (Mode 2) | TFT/touch → Mode 0
I2C:        400kHz, Wire.begin(SDA=3, SCL=43)

7. TMC2209 MOTOR DRIVER ADDRESSING (U5 / U6) — MKS V2.0 modules,
   field-jumpered as of v3.4 (was hardwired through v3.3)
----------------------------------------------------------------

Driver   Ref  MS1 jumper (JMP_MS1_Tn)   MS2 jumper (JMP_MS2_Tn)   UART Addr
-------  ---  ------------------------  ------------------------  ---------
Motor 1  U5   GND (no shunt)            GND (no shunt)            0
Motor 2  U6   3.3V via 10kΩ (shunt)     GND (no shunt)            1

Shared half-duplex PDN_UART bus: GPIO4 (TX) + GPIO44 (RX), joined by
R_UART (1kΩ), bus pull-up R_PDN_UP (10kΩ to 3.3V). Each module's PDN pin
is selected by its own 3-pin jumper (JMP_U5 / JMP_U6):
  - Shunt 2-1 (DEFAULT, v3.4): module pin 5, DIRECT — corrected v3.4 after
    physical inspection of the MKS V2.0 module's own silkscreen.
  - Shunt 2-3 (FALLBACK): module pin 4, via the module's own R8 resistor.
  - NEVER shunt both sides at once.
Both PDN legs route through a 220Ω GPIO protection resistor
(R_gpPDN_T1/T2) before reaching the jumper.

MS1/MS2 pull-up caution: the external 10kΩ pull-up fights the TMC2209's
own internal pull-down. Bench-verify the resulting high level against VIH
(~2.31V) before trusting an address bit — see brief §7.2.

----------------------------------------------------------------
8. LOAD CELLS — 2x HX711, shared clock (added v3.2)
----------------------------------------------------------------

Module          GND   DT (DOUT)          SCK (PD_SCK)   VCC
--------------  ----  -----------------  -------------  -----
HX711 #1 (SK4)  GND   GPIO42             GPIO37 (shared) 3.3V
HX711 #2 (SK5)  GND   GPIO21             GPIO37 (shared) 3.3V

VCC is 3.3V — do NOT power from 5V (DT would also read 5V and damage the
ESP32 GPIO). RATE jumper on each XFW-HX711 module set to 80Hz (not 10Hz).
SCK is shared between both modules; DT is separate per module — needs a
custom bit-bang driver (standard single-clock HX711 libraries don't apply).
Load-cell side wired to each module's own E+/E-/A+/A- screw terminal
(channel A, gain 128); channel B (fixed gain 32) left spare on the module.

----------------------------------------------------------------
9. TURBIDITY SENSING — I2C, shared bus (added v3.2)
----------------------------------------------------------------

Device     Addr   Mode                          Notes
---------  -----  ----------------------------  --------------------------
APDS9960   0x39   ALS, clear-channel, transmission  External LED hardwired ON via J16 (3.3V → 330Ω → LED+)
MAX30102   0x57   Backscatter, own onboard LEDs      18-bit ADC, hardware ambient cancellation

Bus: GPIO3 (SDA) / GPIO43 (SCL), 400kHz, one 4.7kΩ pull-up pair near U1.
Both modules connect via J15 (3.3V/GND/SDA/SCL). No address conflict.
Bring-up: I2C scanner should show both 0x39 and 0x57.
