EMBO Debug Console + UAS Frequency Sweep

Talks to the same BLE debug console used over a terminal app (Nordic UART Service) — no separate firmware GATT service needed. Requires Web Bluetooth (Chrome or Edge, desktop or Android) served over http(s) — if you double-click this file and it opens as a file:// URL, Connect will likely fail silently. Run python3 -m http.server in this folder and open http://localhost:8000/uas_debug_dashboard.html instead.

Automated Frequency Sweep idle
