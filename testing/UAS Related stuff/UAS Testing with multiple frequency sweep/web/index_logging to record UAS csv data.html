Firmware Log

Requires Chrome or Edge with Web Bluetooth enabled. Every strip chart shows the last ~30s of samples, auto-scaled to the data currently on screen — read the numeric value for an exact figure. Jog buttons are press-and-hold — releasing (mouse up / touch end / pointer leaving the button) immediately sends a stop command. The firmware also auto-stops a jogging motor if no command is received for 300ms, in case the BLE link drops mid-press.
