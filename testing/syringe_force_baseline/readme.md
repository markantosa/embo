steps to use
1. plug into the LEFT usbc port of the esp, esp should power on 
2. left button (rst button on esp) resets the whole esp, acts as a tare (because it tares everytime it restarts)
3. run the file fetch_csv.py, it should say Connected, waiting for test
4. right button (boot button on esp) starts the test, it should start logging data to the laptop
5. press the right button to stop the test
6. data should be logged in a csv in test_results folder
7. can use plotresults.py to plot into a graph (requires editing of the python script to open the correct file)
8. if these data collection methods are not good enough / not to your needs then pls generate another tyvm
